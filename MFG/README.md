# MiniERP2_MFG — 제조원가관리

MiniERP2와 별개로 실행하는 제조원가 프로그램이에요. 원료 단가부터 배합(제조법), 용량별 완제품 단가, 판매 SKU 원가까지 관리하고, **확정한 원가만** MiniERP2 마스터 원가로 보내요.
기획은 [docs/MFG_PLAN.md](../docs/MFG_PLAN.md), 현황 분석과 엑셀↔품목 대응표는 [docs/COST_MANAGER_DRAFT.md](../docs/COST_MANAGER_DRAFT.md)에 있어요.

## 실행
- MiniERP2 메뉴: **기준정보 → 제조원가관리(MFG)**.
  - 실행 파일을 처음 못 찾으면 위치를 물어보고, 한 번 지정하면 기억해요.
- 직접 실행: `MFG\bin\Debug\net10.0-windows\MiniERP2_MFG.exe`.
  - 이미 떠 있으면 새로 뜨지 않고 기존 창이 앞으로 와요.

## 데이터 위치
| 항목 | 위치 |
|---|---|
| mfgdb | `%AppData%\MiniERP2_MFG\mfgdb.sqlite` (MiniERP2 DB와 별개) |
| 백업 | `%AppData%\MiniERP2_MFG\backups\` |
| 설정 | `%AppData%\MiniERP2_MFG\settings.json` |
| 이관 리포트 | `%AppData%\MiniERP2_MFG\import_report_*.txt` |

- 백업 규칙은 MiniERP2와 같아요.
  - 수동·작업 전 백업: 최신 3개 유지
  - 종료할 때 일일 백업: 2개월 유지
  - 월간 백업: 매월 1일 종료 시 물어봄
- 시험 실행: 환경변수 `MFG_DATA_DIR=<폴더>`를 지정하면 실사용 mfgdb 대신 그 폴더를 써요.

## 코드 체계 (2026-10-21 변경)
모든 MFG 코드는 `mfg_`로 시작해요.

| 대상 | 규칙 | 예 |
|---|---|---|
| 원료 | master DB(MiniERP2 품목)에 그 원료를 소분 판매하는 SKU 계열이 있으면 기본 SKU를 차용 | master `cocog`(코코글루코사이드 1L) → `mfg_cocog` |
| 원료(차용할 것 없음) | 번호 코드 — [데이터 관리]에서 파일로 고치세요 | `mfg_rm001` |
| 부자재 | 번호 코드 | `mfg_pk001` |
| 제조법 | mfg_ + 분류(c/s/h/d) + 번호 | `mfg_h14` |
| 완제품 | MiniERP2 SKU 그대로(원가 전송 연결 키라서 바꾸지 않음) | `foam300` |

- 2026-10-21 기준 원료 137개 중 41개를 차용했고, 96개는 `mfg_rm###`예요.
- [설정·백업] → **원료 코드 master 차용**을 다시 누르면, master에 새로 생긴 SKU 계열을 번호 코드 원료에만 적용해요(직접 고친 코드는 그대로).
- 코드는 내부적으로 Id로 연결돼 있어서, 코드를 바꿔도 배합·단가·완제품 연결이 그대로 유지돼요.

## 데이터 관리 (파일 일괄수정 — MiniERP2와 같은 기능)
[데이터 관리] 탭에 표가 12개 있어요: 원료 / 원료단가 / 혼합물구성 / 부자재 / 부자재단가 / 제조법 / 배합행 / 제조법용량 / 용량별원가 / 완제품 / 묶음구성 / 매입처.
1. **엑셀 내보내기**: 열을 고르고, 필요하면 한 열=값 필터를 걸어요. 내보낸 기록은 "내보내기 기록" 탭에 남아요.
2. 엑셀에서 고쳐요.
   - **Id 열은 고치지 마세요.** 행을 맞추는 열이에요. 새 행은 Id를 비워 두면 돼요.
   - 회색 머리글 열은 참고용이라 고쳐도 반영되지 않아요.
3. **엑셀 불러오기**: 기존 행은 Id로 맞추고, Id가 없으면 코드나 SKU로 맞춰요. 이때 "덮어쓰기 + 신규 추가"와 "신규만 추가" 중에 골라요. 이 단계에서는 화면에만 반영되고 아직 저장되지 않아요.
4. **변경내역 저장**: 저장하기 직전에 mfgdb를 자동으로 백업하고, 한 번에 반영해요. 한 행이라도 실패하면 전부 취소돼요.
   - 되돌리려면 "백업/롤백" 탭에서 복원하세요.
- 그리드에서 직접 고치거나 엑셀처럼 복사·붙여넣기(Ctrl+C/V)해도 돼요.
- 다른 표를 가리키는 칸(원료코드·부자재코드·제조법코드·SKU)은 코드로 적어요.
- 화면 없이 코드 변환만 하려면: `MiniERP2_MFG.exe --migrate-codes`

## 금액 규칙
- 모든 단가는 **VAT포함으로 저장**해요. 상단 [VAT포함 보기 | VAT별도 보기]는 표시만 바꿔요(면세 원료는 그대로).
- 엑셀에서 가져온 가격은 VAT별도라서 ×1.1로 저장했어요. VAT별도 보기로 바꾸면 엑셀 숫자와 같아요.
- MiniERP2로 보내는 값은 product_master와 같은 구성(원료+용기+패키지+스티커 등+기타+택배비)의 **VAT포함 합계**예요.

## 쓰는 순서
1. **원료**: 단가가 바뀌면 [단가 추가]로 새 단가를 입력해요. 이력은 남고, 가장 최근 적용일 단가가 현재 단가가 돼요.
   - 신규 원료 코드(RM###)는 자동으로 붙어요.
2. **부자재**: 용기·캡·라벨·박스 단가를 원료와 같은 방식으로 관리해요.
3. **제조법**:
   - 배합표: 원료를 더블클릭해서 고르고, 목록에 없으면 그 자리에서 신규 등록해요.
   - 비중: 계산 비중이 자동으로 나오고, 실측 비중을 넣으면 그 값을 써요.
   - 용량별 완제품 단가표: 부자재 칸은 금액을 직접 입력하거나, 우클릭해서 부자재 목록에 연결해요.
   - **[확정]**: 그 시점 계산 결과를 이력으로 남겨요. 확정한 제조법을 고쳐 저장하면 미확정으로 돌아가요.
     원료 단가가 바뀌어도 확정한 원가는 그대로이고, "재확인 필요" 표시가 떠요.
4. **완제품 원가**(product_master 대체):
   - 품목마다 원료 열을 *제조법 용량 / 원료 소분 / 묶음 / 수동값* 중 하나에 연결하고 [확정]해요.
   - "연결 후보" 열은 이관할 때 유추한 대응 제조법이에요(신뢰도·코멘트 포함). 반드시 확인한 뒤 연결하세요.
5. **MiniERP2 전송**: 확정 원가와 MiniERP2 원가가 다른 품목만 보여요.
   - 체크한 것만 전송하고, 전송 전에 MiniERP2 DB를 자동으로 백업해요.

## 초기 데이터 (2026-10-21 세팅 완료)
- 가져온 엑셀: `제조법관련(신규).xlsx`(원료 137, 단가이력, 혼합물, 배합 61), `product_master.xlsx`(부자재 57, 판매 품목 609).
- **모든 제조법·완제품은 미확정**이에요. 실제로 쓰면서 확인한 것부터 확정 표시하세요.
- 다시 가져오기: [설정·백업] 탭 버튼, 또는 `MiniERP2_MFG.exe --seed --force`.
  - 기존 데이터는 백업한 뒤 지우고 다시 가져와요.
