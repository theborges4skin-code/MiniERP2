## 1. 현재 구조

### 1-1. PM (product_master.xlsx)
- 시트 1개 `오픈마켓(26.01.~)`, 판매 품목 약 690행(SKU 있는 행 575개).
- 열: 구분 / 상품그룹 / 상품명 / SKU / 소비자가 / **제조원가(VAT포함)=J×1.1** / 마진 / 이익액 / **제조원가(VAT별도)=SUM(K:P)** / K 원료 / L 용기 / M 패키지 / N 스티커 등 / O 기타 / P 택배비 / Q~T 비고.
- **노란 셀(사용자 입력)은 거의 K열(원료)뿐이다**(228개, 그 외 N 8개·P 5개·O/L 각 1개). 나머지는 수식이다.
- K열은 다른 셀을 참조하지 않는다. 숫자를 직접 넣거나(`=(3300)*1.03/2` 같은 손계산 포함) 제조법 파일에서 계산한 값을 옮겨 적은 것이다. 시트 간 참조나 외부 파일 링크는 하나도 없다.
- **MiniERP2 연동 확인**: `ItemTable.CostPrice` = PM G열(VAT포함). 561개 중 527개가 소수점까지 같다. `Reserve1` = PM 소비자가. 나머지 34개는 PM이나 DB 중 한쪽만 갱신된 것으로 보인다.
- 행 유형은 크게 네 가지다.
  1. **자체 제조품**(핸드워시·면도기세정액·요석·커피·디퓨저 등): K = 배합 원료비. 일부 품목은 K에 용기·스티커까지 포함한 "단품 전체 원가"가 들어 있다. 예: `foam300` K=1149 = 신제조법 H14 300ml 제조원가 1149.4.
  2. **원료 소분 판매품**(추출물·계면·VG·피마자 등, 약 300행): K = 원료 kg단가 × 용량 × 계수, L = 용기 단가.
     - ⚠️ 계수가 1.03·1.05·1.1·1.15·1.25로 제각각이다. 로스율인지, 운임인지, 단가 인상분인지 모른다.
  3. **묶음/세트/채널상품**(쿠팡그로스·로켓, 1+1, 3개세트 등): K = 단품 원가 × 수량, O·P = 박스·입고비·택배비 배분.
  4. **부자재 단가표**(999.미분류 `기타(부자재)` 57행): 용기·뚜껑·박스 단가. 예: `대동, 4L 말통` 1240, `대동, 54파이 뚜껑` 150.
     - 다른 행의 L열에 `=1240+150`처럼 **값을 손으로 옮겨 적어서** 쓴다. 참조가 아니므로 용기 단가가 바뀌면 일일이 고쳐야 한다.

## 2. 원가가 만들어지는 흐름 (현재 실제 업무)

```
원료 단가(원/kg, VAT별도) ─┐
                          ├─▶ 배합(레시피) kg당 원료비 ─▶ 용량별 원액비 = kg당 × 용량 × 비중
혼합물 구성(전성분용)  ────┘                                     │
                                                              ▼
부자재 단가(용기·캡·라벨·박스) ───────────────▶ 단품 제조원가(VAT별도) = 원액비 + 부자재 + 임가공
                                                              │
                                                              ▼
                              묶음/세트/채널상품 원가 = Σ(구성 단품 × 수량) + 박스·입고비·택배비 배분
                                                              │
                                                              ▼
                              PM J열(VAT별도) → G열(×1.1) → MiniERP2 ItemTable.CostPrice
```

지금은 모든 화살표가 사람 손으로 이어진다. 프로그램은 이 화살표를 자동으로 잇는 것이 목적이다.

## 3. 프로그램 설계 초안

### 3-1. 형태 (단독 실행 + MiniERP2 연동)
- MiniERP2 저장소 안에 **별도 실행 프로젝트**를 둔다(가칭 `CostManager`, WinForms .NET 10). MiniERP2와 같은 기술 스택을 쓴다.
  - 단독 실행: `CostManager.exe`를 따로 실행한다.
  - 연동: MiniERP2 메인 허브에 "제조원가관리" 메뉴를 추가하고 같은 화면을 띄운다. 코드는 공유한다.
- DB는 **별도 파일** `CostMaster.sqlite`를 쓴다. MiniERP2 없이도 동작해야 하므로 MiniERP2 DB에 테이블을 두지 않는다.
- MiniERP2로 원가를 보내는 방향은 단방향이다: "MiniERP2에 원가 반영" 버튼을 누르면 SKU 기준으로 `ItemTable.CostPrice`(VAT포함)를 갱신하고 `ItemCostHistory`에 이력을 남긴다. 반영 전에 변경 전/후 미리보기를 보여준다.

### 3-2. 데이터 모델 (요약)
| 테이블 | 내용 |
|---|---|
| `Material` 원료 | 코드(**자동 채번** RM###), 원료명, 별칭(구 표기명 여러 개), 전성분명, CAS, 역할, 비중, 공급처, 혼합물 여부, 비고, 단가확실도 |
| `MaterialPrice` 원료단가이력 | 원료, 단가(원/kg VAT별도), 적용일, 출처(견적/거래명세/사용자확정), 메모. **최신 적용일 단가를 현재 단가로 쓴다** |
| `MaterialComponent` 혼합물구성 | 혼합 원료 → 전성분·CAS·비율 |
| `Recipe` 배합 | 코드(C/S/H/D + 번호, 자동 채번), 제품명, 버전(예: "260430 용기원료인상반영"), 상태(생산중/개발중/폐기), 적용 비중, 메모 |
| `RecipeLine` 배합행 | 원료, 투입량 %, 공정 메모 |
| `PackMaterial` 부자재 | 코드, 거래처, 품명(예: "대동, 4L 말통"), 단가, 이력. PM `기타(부자재)` 57행에서 가져온다 |
| `CostProduct` 원가품목(=판매 SKU) | SKU(MiniERP2와 동일), 상품명, 유형(단품/묶음/소분판매/외부매입), 배합+용량 또는 원료+용량, 부자재 목록, 기타·택배비 배분식 |
| `CostProductComponent` 묶음 구성 | 묶음 SKU → 구성 SKU × 수량 |

PM의 "K=단품원가×2" 같은 묶음 행은 `CostProductComponent`로 표현한다. 그러면 단품 원가가 바뀔 때 묶음 원가도 자동으로 다시 계산된다.

### 3-3. 화면 (1차)
1. **원료 관리**: 목록·검색(원료명/별칭/CAS), 신규 등록(코드 자동), 단가 입력(이력 누적), 단가 변동 시 영향받는 배합·SKU 목록.
2. **배합 관리**: 배합 목록, 배합행 편집(원료 검색 드롭다운, 투입량 합계 검증), kg당 원료비 실시간 계산, 전성분(함량순) 자동 생성, 배치 계량표, 버전 복사.
3. **부자재 관리**: 용기·캡·박스 단가와 이력.
4. **SKU 원가표**(PM 대체): PM과 같은 열 구성(원료/용기/패키지/스티커/기타/택배비 → VAT별도·포함, 마진). 원료 열이 배합에서 자동으로 계산된다. 노란 셀처럼 수동 입력 칸(덮어쓰기)도 허용하되, 수동값에는 표시를 남긴다.
5. **원가 변동 시뮬레이션**: "원료 X 단가를 Y로 바꾸면" → 영향받는 SKU와 원가·마진 변화를 표로 보여준다.
6. **MiniERP2 반영 / 엑셀 내보내기**(PM 양식 그대로).

### 3-4. 기존 자료 이관 순서
1. 신제조법 `원료목록` → `Material` 136종. 단가는 `MaterialPrice` 최신값, `단가이력` 약 350건은 이력으로 넣는다.
2. 신제조법 `혼합물구성` → `MaterialComponent`.
3. 신제조법 배합 시트 61개 → `Recipe`/`RecipeLine` + 시트 하단 용량별 부자재 값.
4. PM `기타(부자재)` → `PackMaterial`.
5. PM 전체 행 → `CostProduct`. 처음에는 **PM 값을 그대로 수동값으로 가져온다**(현행 원가와 동일하게 시작). 이후 §5 매핑이 확정된 SKU부터 "배합 연결"로 바꾼다. 바꿀 때 PM 값과 계산값의 차이를 보여주고 사용자가 승인하게 한다.
6. 구제조법은 신제조법이 이미 흡수했으므로 직접 이관하지 않는다. 신제조법에 빠진 시트(`고체연료(개발중)`, `영업관련 메모`, `Sheet3 원본` 등)는 §6 질문 참조.

## 4. 확인된 사실 (근거 있음)

- 신제조법 H14 핸드워시 300ml 제조원가 1,149.4 = PM `foam300`/`igfoam300`/`cprfoam300*` K=1,149. 500ml 1,335.0 = `igfoam500` K=1,335. → **핸드워시는 PM K열에 "단품 전체 제조원가"가 들어 있다.**
- PM 화장품·소분 행은 같은 제품군 안에서 PM값/레시피 계산값 비율이 일정하다. 대응 관계는 맞고 단가 시점이나 계산 방식만 다르다는 뜻이다. 아래 §5에 비율을 함께 적었다.
- 비율이 1/비중과 거의 같은 경우가 많다. 예: 콜라겐 세럼 비중 0.95 → 비율 1.05. 즉 **PM은 비중을 무시하고 ml=g로 계산**해 왔고, 신제조법은 비중을 반영한다. ⚠️ §6-Q2 참조.

## 5. 배합(신제조법) ↔ PM 품목 대응표 (유추)

신뢰도: **높음** = 이름과 숫자가 모두 맞음 / **중간** = 이름은 맞지만 숫자 차이가 있음 / **낮음** = 이름만 비슷함 / **없음** = PM에 대응 품목을 못 찾음.
"비율" = PM K ÷ (신제조법 kg당 원료비 × 용량 × 비중). 1.00에 가까울수록 일치한다.

| C02 콜라겐 세럼 | 535~537 `amzcps10/15/30` | 높음 | 비율 1.05 (비중 0.95 미반영 차이) |
